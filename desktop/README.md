# GIS 주소 변환기 — 데스크톱 (Windows)

엑셀/CSV 주소 목록을 **PNU · 좌표 · QGIS 레이어(GeoJSON)** 로 일괄 변환하는 데스크톱 앱.
[웹 버전](../streamlit_app.py)과 같은 병렬 엔진을 쓰지만, **로컬 실행이라 연결 끊김·타임아웃이 없어 대용량(수만 행)** 작업에 적합합니다. (VWorld 는 한국 IP에서만 정상 동작 — 웹은 해외 클라우드 IP가 차단되지만, 이 데스크톱 앱은 사용자 PC(한국 IP)에서 직접 호출하므로 안정적)

## 기능
- ① 주소 → PNU (정제주소·본번·부번, 도로명주소·건물명, 공시지가 옵션)
- ② 주소 → 좌표 (위경도 EPSG:4326 / 중부원점TM EPSG:5186)
- ③ QGIS 레이어 (포인트·필지 경계 GeoJSON)

출력은 **원본 열을 그대로 두고 결과 열을 오른쪽에 덧붙인** `<원본이름>_결과.xlsx`. PNU 등 긴 숫자는 텍스트로 저장돼 엑셀에서 지수표기(1.15E+18)로 깨지지 않습니다.

## 엔진 — 기본은 카카오
| | 속도 | 일일 한도 | 할 수 있는 것 |
|---|---|---|---|
| **카카오** (기본) | 초당 33건 | **10만건** | PNU · 좌표 · 도로명주소 · 건물명 |
| VWorld | 초당 14건 | 4만건 | 위 + **필지 경계 · 공시지가** |
| 코드 조합 | 즉시(무통신) | 없음 | PNU (파일에 법정동코드가 있을 때) |

3만 행이면 카카오 약 15분, VWorld 약 35분입니다. **필지 경계나 공시지가가 필요할 때만** VWorld 로 바꾸세요.

## 도로명주소 · 건물명
카카오 응답에 딸려 오므로 **추가 호출이 없습니다**(속도·한도에 영향 0). 결과 열 `도로명주소`·`건물명` 에 채워집니다.

```
서울 송파구 문정동 651-11  →  서울 송파구 법원로8길 8  ·  문정역2차 SK V1
```

다만 **도로명주소는 건물이 있어야 붙습니다.** 논밭·도로·구거는 빈칸이에요. 토지대장 실측(아산 29,566행)에서 도로명 17.8% / 건물명 1.2%였고, 지목이 `대` 인 필지만 보면 도로명 67.5%였습니다. 도심 지역은 훨씬 높습니다.

> VWorld 엔진·코드 조합 모드에서는 빈칸입니다(VWorld 지오코더는 도로명주소를 주지 않고, 코드 조합은 통신을 하지 않음).

## 처음 설정 (아주 간단)
1. `주소PNU변환기.exe` 실행.
2. 앱 위쪽 **🟡 카카오 REST 키** 칸에 본인 키를 붙여넣고 **[확인·저장]** 클릭.
   - 키가 없으면 developers.kakao.com → 내 애플리케이션 → 앱 키 → **REST API 키**.
   - ⚠ 같은 화면에서 **"카카오맵" 제품을 반드시 활성화**하세요. 안 하면 403 오류가 납니다.
3. (선택) 필지·공시지가를 쓰거나 카카오 실패분을 보완하려면 **🔑 VWorld 인증키** 도 함께 넣으세요.
   - 옆의 **vworld.kr 열기** 버튼으로 무료 발급 (활용 API "2D 데이터 API" 체크, 사이트 URL `http://localhost`).
4. 끝. 키는 자동으로 저장돼 **다음에 켜면 그대로 기억**됩니다. 파일을 직접 편집할 필요 없어요.

### 인증키가 저장되는 곳
`%APPDATA%\GIS주소변환기\config.txt` (탐색기 주소창에 `%APPDATA%\GIS주소변환기` 붙여넣으면 열립니다).

**exe 옆이 아니라 사용자 폴더에 저장**하므로 — 새 버전 exe 로 바꿔도, 폴더를 옮겨도 **키를 다시 넣을 필요가 없습니다.** Program Files 처럼 쓰기 막힌 곳에 둬도 저장돼요.

> exe 옆에 이미 `config.txt` 가 있으면 그쪽을 그대로 씁니다(기존 사용자·USB 포터블 사용을 깨지 않기 위해). USB로 들고 다니며 쓰고 싶으면 exe 옆에 빈 `config.txt` 를 만들어 두세요.

> 각자 자기 키를 앱에 한 번 넣으면 됩니다. `config.txt` 를 손으로 만들 필요가 없어요(고급 사용자는 편집해도 됨 — 아래 `config.txt.example` 참고).

## 배포 (다른 사람에게 줄 때)
- **`주소PNU변환기.exe` 파일 하나만** 주면 됩니다. 받은 사람은 실행 후 자기 인증키를 칸에 넣으면 끝.
- ⚠️ **내 키가 든 `config.txt` 는 함께 주지 마세요** (남이 내 사용량을 씀). exe 만 주면 상대는 자기 키를 넣습니다.
- exe 를 처음 실행하면 `%APPDATA%\GIS주소변환기\config.txt` 가 자동 생성됩니다. 받는 사람은 앱에서 자기 키를 한 번 넣으면 끝이고, 이후 새 버전 exe 를 줘도 다시 넣을 필요가 없습니다.

## 소스로 실행
```bash
pip install -r requirements.txt
python app.py
```

## exe 빌드 (PyInstaller)
```bash
pip install -r requirements.txt
python -m PyInstaller --noconfirm --onefile --windowed --icon=icon.ico ^
  --add-data "icon.ico;." --collect-all tkinterdnd2 --distpath dist --name 주소PNU변환기 app.py
```
- 빌드 결과: `dist/주소PNU변환기.exe`. 설정은 `%APPDATA%\GIS주소변환기\config.txt` 에 자동 생성됩니다(exe 옆에 `config.txt` 가 있으면 그쪽 우선).
- 기존 exe 가 **실행 중이면 잠겨서 빌드 실패** → 창을 닫거나 `--distpath` 를 다른 폴더로.

## 토지대장처럼 "대장구분(산/일반)" 열이 있는 파일 ⚠️ 중요
산 지번은 **"배미동 24-4" 가 아니라 "배미동 산 24-4"** 로 조회해야 합니다. 산을 빼고 물으면
① 그런 번지가 없어 실패하거나, ② **같은 번호의 일반 필지에 잘못 매칭**됩니다(오류가 안 떠서 더 위험).

→ 주소 열 확인창의 **`대장구분(산) 열`** 에 해당 열을 지정하세요(제목이 `대장구분`·`산구분`·`산여부` 면 자동으로 잡힙니다).
값이 `산`·`임야`·`Y`·`2` 인 행은 지번 앞에 `산` 이 붙습니다.

추가로 결과 PNU 의 11번째 자리(1=일반, 2=산)를 대장구분과 **교차 검증**합니다. 지오코더가 반대쪽
필지를 물어오면 그 값을 버리고 상태열에 `산일반불일치` 로 표시합니다 — 틀린 PNU 가 조용히 섞이지 않습니다.

> 실측(아산 토지대장 29,566행): 이 열을 지정하지 않으면 산 필지 1,522건 중 1,177건 실패 + 345건이
> 일반 필지 PNU 로 잘못 부여됨. 지정 후 1,455건 정답, 오답 0.

## 카카오 실패분 VWorld 자동 보완
카카오 주소검색은 도로명주소 DB 기반이라 **도로·구거처럼 미등록 지번이 통째로 빠집니다.**
카카오 모드에서 못 찾은 주소는 자동으로 VWorld 에 한 번 더 물어보고, 채운 행은 상태열에 `OK(VWorld)`
로 남습니다(위 🔑 칸에 VWorld 키가 있어야 동작. 없으면 조용히 건너뜁니다).
위 실측 파일 기준 카카오가 못 찾은 188건 중 60건이 이렇게 채워졌습니다.

## 대용량 팁 (통신실패가 많다면)
- `config.txt` 의 `WORKERS` 값을 줄이세요(예: 4 → 3). VWorld 가 동시 연결이 많으면 끊습니다.
- 공시지가 옵션은 주소당 조회가 2배라 대용량에선 느리고 일일 한도에 빨리 닿습니다.
- 그래도 통신실패가 남으면, 잠시 뒤 실패분만 추려 다시 돌리면 대부분 채워집니다.
- 상태열이 `주소인식실패` 로 남는 건 두 지오코더 모두 모르는 필지입니다(분할·합병으로 생긴 자투리
  도로·구거가 대부분). 이건 조회로는 못 채우고 연속지적도 매칭이 필요합니다.
